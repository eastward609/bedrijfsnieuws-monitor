IssuerScope installeren

Je dagelijkse monitor voor officieel bedrijfsnieuws · online, zonder programmeerkennis

Wat krijg je?

Een openbaar online dashboard dat automatisch elke dag om 07.23 uur Belgische tijd officiële bedrijfsbronnen controleert. De monitor blijft lopen wanneer je computer uit staat. Je maakt één keer een gratis GitHub-project aan. De bedrijvenlijst is daarna via een formulier aanpasbaar.

Deze website is een installatiehandleiding, niet de actieve monitor. De echte monitor staat pas online wanneer je de onderstaande stappen in je eigen GitHub-account hebt voltooid.

Eenmalige installatie

  1. Maak een GitHub-account en daarna een lege public repository met de naam bedrijfsnieuws-monitor. Zet Add a README uit.
    1. Maak een GitHub-project ↗
  2. Pak het geleverde ZIP-bestand uit. Upload alle bestanden én mappen uit de projectmap via GitHub Add file → Upload files. Vergeet de verborgen map .github niet; op een Mac wordt die zichtbaar met Cmd + Shift + .. Gebruik liefst Chrome of Edge om de map te verslepen. Klik Commit changes.
  3. Open in je project Settings → Pages en kies bij Source: GitHub Actions.
  4. Open Actions → Dagelijkse bedrijfsmonitor → Run workflow en start verversen. De eerste verwerking haalt nieuws op van de twee voorbeeldbedrijven Apple en Volkswagen.
  5. Open opnieuw Settings → Pages; daar staat het dashboard-webadres. Klik op de link en bewaar die als favoriet.

Het dashboardadres is gewoonlijk https://JOUWNAAM.github.io/bedrijfsnieuws-monitor/.

Bedrijven toevoegen of verwijderen

Open Actions → Dagelijkse bedrijfsmonitor → Run workflow. Kies bij actie:

  • toevoegen: vul de bedrijfsnaam, de officiële website, de officiële bron-URL en optioneel de beurscode in.
  • verwijderen: vul de exacte bedrijfsnaam in.
  • verversen: haal nu het nieuwste nieuws op.

De hele monitor wordt automatisch opnieuw gepubliceerd. Voor 100+ bedrijven kun je het bestand bedrijven.csv in Excel bewerken en vervangen in GitHub.

Belangrijke grenzen

Je volgt uitsluitend officiële, door het bedrijf beheerde bronnen. Je moet eerst voor ieder bedrijf de juiste RSS-feed of nieuwspagina toevoegen. Sommige websites blokkeren geautomatiseerde controle of laden berichten met JavaScript; controleer dan het tabblad Broncontrole.

De gratis GitHub Pages-versie is publiek: iedereen met de URL kan de bedrijvenlijst en het nieuws zien. Gebruik dit niet voor vertrouwelijke werkgegevens.

Een geautomatiseerde GitHub-run kan uitgesteld of overgeslagen worden en kan bij 60 dagen repo-inactiviteit worden gedeactiveerd. Controleer daarom regelmatig de laatste controledatum.
